# Pfad der Klingen – Testversion im Browser

Pixel-Roguelike im Stil von Slay the Spire (Arbeitstitel). Hier liegt nur das fertige Spiel für den Browser;
der Quellcode ist privat.

**Spielen:** https://saytrix08.github.io/rpg-play/

Auf dem iPad oder Handy: Link in Safari öffnen → Teilen → **Zum Home-Bildschirm**, danach über das Symbol starten.
